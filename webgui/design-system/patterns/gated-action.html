The rule

  • Available → the PatternFly button, nothing else.
  • Unavailable in this environment → aria-disabled (focusable, announced) with the reason as text beside it, naming the object that does hold the setting. Never a host command in a cluster, never a bare tooltip.
  • Works with a caveat → enabled, the caveat marked with a warning rule — as text, in the regular text colour.
  • Not this person's tier → not rendered; the environment bar carries the explanation.
  • The reason strings come from /api/environment (capabilities[cap].reason) — the SPA does not write its own.
